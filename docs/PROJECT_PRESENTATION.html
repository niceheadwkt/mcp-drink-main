專案緣起與核心痛點

為何我們需要智慧化的飲品點購方案？

傳統團購的瓶頸

  • 人工統計混亂：每到下午茶，統計品項、加料、冰甜規格繁雜，極易出錯。
  • 流程死板繁複：需要發起人逐一建立表單，或大家在群組刷訊息，不易彙整。
  • 重複訂單漏洞：多人代點、二次點餐導致點錯或多點，造成浪費。

智慧化突破口

  • 對話式語意點單：用語音或口語直接說：「一杯粉粿檸檬去冰無糖」，AI 自動處理。
  • 主動除錯與驗證：系統自動過濾重複點單，語意自動填補，規避常規出錯。

前端美學與使用者體驗 (UX/UI)

極致毛玻璃微動畫與雙模式 AI 助手

PWA 毛玻璃極致前端 (Port: 8000)

  • 玻璃擬物設計 (Glassmorphism)：半透明毛玻璃特效，創造高端商用體驗。
  • 無縫 PWA 安裝：支援手機安裝至主畫面，提供滿版 RWD 佈局與 iOS 安全底邊邊距。
  • 動態試算：加料與基底價格即時變更，一鍵推送雲端。

Streamlit 管理側邊欄 (Port: 8501)

  • 雙模式 AI 引擎：完美支援雲端模型（Gemini/Claude）及本地 Ollama 模型。
  • 本地模型自動偵測：一鍵偵測本地運行的 Ollama，並優先推薦 `gemma4`。
  • 離線安全性：本地模式免 API Key，保障隱私與資安。

MCP (Model Context Protocol) 技術解密

AI Agent 連接現實世界的標準協定

什麼是 MCP？ MCP 是一套開放協定，讓大語言模型 (LLM) 擺脫只聊天的局限，直接獲得調用內部資料庫、寫入檔案、刪改資料等「主動執行」的能力。

專案 FastMCP Tools 清冊

  • `get_menu`：暴露即時菜單結構供 AI 比對。
  • `place_drink_order`：口語化解析，自動計價並儲存。
  • `update_drink_order`：智慧更新，如「把剛才那杯改成去冰」。
  • `delete_drink_order`：取消訂單或特定人的單子。

查重與統計 Tools

  • `search_all_duplicates`：掃描資料庫中潛在的重複點單。
  • `get_duplicate_statistics`：分析重複訂單的比率與重複王。
  • 讓 AI 助手能在一秒內為發起人整理出「點單分析報告」。

後端資料庫與強大容錯設計

確保系統流暢無阻的基石

RapidFuzz 模糊匹配

  • 使用者說「桂花檸檬」，自動對應選單中「粉粿桂花檸檬」。
  • 容許語意口誤與同音字，顯著提升 AI 助理的調用成功率。

類型安全與 Pydantic 修復

  • 徹底修復修改訂單時傳遞 None 產生的類型驗證錯誤。
  • 導入 `Optional[str]` 的安全校正，實現無間斷運行。
雲端同步：採用 Google Cloud Firestore 以 Singleton 單例模式運行，確保高併發下連線數最小化，速度最快。
